# プライバシーポリシー差し替え手順

この文書は、`manage.ka2.org` の WordPress 固定ページを更新し、Cloudflare Pages で配信する `https://ka2.org/privacy-policy` に反映するための差し替え案と手順です。

## 公開前に確認すること

- お問い合わせ情報は WordPress の Flamingo に保存されます。現在、保存データの自動削除期間は設定されていません。この案では一律の日数を約束せず、問い合わせ対応・記録に必要な期間としています。実運用では定期的に保管の必要性を確認し、不要な記録を削除してください。
- 運営者名は公開プロフィールと合わせて「Ka2（カツ）」としています。正式な事業者名・住所等の掲示が必要な場合は、公開前に追記してください。
- 本案は実装と確認済みの運用に合わせた文案です。法令適合性の最終判断を代替するものではありません。

## 差し替え本文

WordPress 固定ページのタイトルを「プライバシーポリシー」に変更し、本文を次の HTML に差し替えます。スラッグ `privacy-policy` は変更しません。

```html
<p>Ka2（カツ）が運営する Monaural Sound（以下「当サイト」）では、当サイトの提供にあたり取得する情報を、以下のとおり取り扱います。</p>

<h2>お問い合わせ情報の保管</h2>
<p>お問い合わせの内容と送信者情報は、WordPress の管理システムに保存され、運営者への通知メールにも含まれます。お問い合わせ対応および不正利用の確認に必要な期間保管し、保管の必要がなくなった情報は適切な方法で削除します。メールサービスやシステムのバックアップに残る情報は、それぞれのサービスの保存・削除の仕組みに従って取り扱われます。</p>
<p>お問い合わせフォームのスパム対策には Cloudflare Turnstile を使用します。送信時には、確認のために必要な情報が Cloudflare に送信される場合があります。</p>

<h2>アクセス解析</h2>
<p>当サイトは Google Analytics 4 を利用しています。アクセス解析は、Cookie 設定で「同意する」を選択した場合に有効になります。「同意しない」を選択した場合、当サイトから Google Analytics の解析スクリプトを読み込みません。</p>
<p>Google によるデータの取り扱いについては、<a href="https://policies.google.com/privacy?hl=ja" target="_blank" rel="noopener noreferrer">Google のプライバシーポリシー</a>をご確認ください。</p>

<h2>広告配信</h2>
<p>当サイトは Google AdSense による広告を掲載しています。広告配信のため、Google 等の第三者が Cookie 等を使用し、利用者の当サイトや他のウェブサイトへのアクセス情報をもとに広告を表示する場合があります。</p>
<p>Cookie 設定で「同意する」を選択した場合はパーソナライズ広告が、「同意しない」を選択した場合または選択前は非パーソナライズ広告が表示されます。「同意しない」を選択しても広告配信自体は停止せず、広告関連の Cookie 等が一切使用されなくなることを保証するものではありません。</p>
<p>Google の広告における情報の利用や設定方法は、<a href="https://policies.google.com/technologies/ads?hl=ja" target="_blank" rel="noopener noreferrer">Google の広告に関するポリシー</a>をご確認ください。</p>
```

## manage.ka2.org での更新手順

1. `https://manage.ka2.org/wp/wp-admin/` にログインします。
2. 「固定ページ」から、スラッグ `privacy-policy` のページを探します。現在のページ ID は `122192`、現在のタイトルは `Cookie Policy` です。新しいページを作らず、既存ページを編集します。
3. タイトルを「プライバシーポリシー」に変更します。パーマリンクのスラッグは `privacy-policy` のままにします。
4. ブロックエディターで既存本文を置き換えます。本文領域に「カスタム HTML」ブロックを1つ追加し、上のコードブロックの内側にある HTML のみを貼り付けます。コードブロックを囲む Markdown の区切り行は貼り付けません。
5. 「更新」を押します。ページはすでに公開中なので、公開状態を維持してください。
6. 本番の `KA2_DEPLOY_HOOK_URL` は設定済みであることを確認しています。WordPress の Deploy Hook が公開ページ更新を検知し、約60秒のデバウンス後に Cloudflare Pages の再ビルドを要求します。WP-Cron の実行タイミングやビルド時間により反映まで数分かかることがあります。

## 本番反映の確認

- `https://ka2.org/privacy-policy` を開き、タイトル、本文、外部リンク、更新日を確認します。URL が `/privacy-policy` のまま、ページが日本語で表示されることを確認してください。
- フッターのプライバシーポリシーリンクと、`/contact` の同リンクから到達できることを確認します。
- ブラウザーのページソースで `lang="ja"`、新しい本文、古い英語の Cookie Policy 文面が残っていないことを確認します。
- 数分たっても古いページの場合は、Cloudflare Pages の Deployments で本番ビルドの開始・結果を確認します。Deploy Hook が発火していない場合は、成功済みの Production deployment を再試行するか、Pages の再デプロイを手動実行します。
- 表示に問題があれば、WordPress の固定ページリビジョンから直前の内容へ戻して再更新し、再ビルド後に同じ URL を確認します。

## 文面と実運用の継続確認

- Flamingo に保存された問い合わせ情報を定期的に確認し、対応・保管の必要がなくなった記録を削除します。自動削除は現在設定されていません。
- GA4 のスクリプトが「同意する」後にのみ読み込まれ、「同意しない」後には読み込まれないことを確認します。
- AdSense は同意の有無にかかわらず読み込まれます。「同意しない」または未選択では非パーソナライズ広告を要求する現行仕様を文面に反映しています。
- 外部サービスの追加・変更、問い合わせ項目や保存処理の変更があった場合は、本ポリシーも更新します。
